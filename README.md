# HG Creations – Marketing Analytics & Business Insights Platform

This project is developed by **HG Creations** as part of a marketing analytics application that integrates:

- Google Analytics 4 (GA4)
- Google Business Profile API

---

## 🚀 Overview

The application is designed to help businesses analyze and improve their online performance by combining:

- Website analytics (traffic, engagement, conversions)
- Local business data (reviews, customer actions, visibility)

It provides a centralized dashboard with actionable insights for business growth.

---

## ✨ Key Features

- 📊 Fetch and display GA4 analytics data (users, sessions, engagement)
- 🏢 Retrieve Google Business Profile data (locations, reviews, insights)
- 🤖 AI-powered insights using Gemini API
- 📈 Performance tracking and trend analysis
- 📱 Clean and interactive dashboard UI

---

## 🧠 Use Case

This platform is intended for:

- Small and medium businesses
- Local business owners
- Marketing analysts

It helps users understand customer behavior, track performance, and optimize their digital presence.

---

## 🔐 Data Access & Security

- All data is accessed securely using **OAuth 2.0**
- The application only retrieves data for accounts where users have explicitly granted permission
- No unauthorized data access or storage is performed
